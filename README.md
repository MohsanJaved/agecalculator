# 🎂 Modern React Age Calculator

A modern, fast, and feature-rich Age Calculator built with **React 18**, **Vite**, and **Tailwind CSS**.

## ✨ Features

- ⏱️ **Ultra-Precise Age Breakdown**: Exact calculation of Years, Months, Days, Hours, Minutes, and Seconds.
- ⚡ **Live Real-time Ticker**: Watch seconds and time elapsed tick in real-time.
- 🎂 **Next Birthday Countdown**: Shows exact days, hours, minutes, seconds left and which day of the week it will occur on.
- 📊 **Lifetime Statistics**: Summary of total months, weeks, days, hours, minutes, and seconds lived.
- ⭐ **Astrology & Fun Facts**:
  - Sun sign (Western Zodiac) with elemental traits & symbols.
  - Chinese Zodiac animal with lunar cycle calculation.
  - Estimated total heartbeats, breaths, and years slept.
- 🎉 **Confetti & Celebration**: Automatic birthday celebration when the date matches today!
- 📋 **One-Click Share/Copy**: Easily copy your exact age summary to clipboard.
- 📱 **Fully Responsive & Dark Themed**: Glassmorphism design with Tailwind CSS.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
